## Scope and remaining follow-ups

The README no longer characterizes the reduced-torque 20-chunk attempt as a
serving or policy failure. FIRST_CONTACT retains the actual unmet return
check, nonzero exit, torque-off cleanup, and unresolved causal attribution.
No hardware was opened or moved during this release work. Sustained motion
and task success remain unvalidated.

The Trusted Publishing workflow is prepared and disabled until publisher
registration is complete. PyPI requires account-password confirmation for
that setup, so this release uses the saved macOS Keychain publishing
credential. No token was revoked; no Trusted Publishing or attestation claim
is made for a local upload. The upstream security report remains an unsent
draft referring to the existing upstream report and fix.
